# 双师课堂教材 RAG 与可验证讲题设计

## 目标

让高中数学知识点讲解和拍题讲解走同一条可追溯教学链路：输入题目或知识点、检索人教 A 版 2019 教材、生成讲解、做数学与视觉一致性校验，并在无可靠图形时展示教材关联而不是空白或默认实体。

## 已确认事实与边界

- 教材源仅来自 `D:\知识库\AC切片\processed` 的五个人教 A 版 2019 学生教材批次，共 792 个切片。教师用书、题库、研究资料不能进入学生教材证据域。
- 当前开发数据库的 `knowledge_docs`、`chunks`、`knowledge_points` 均为空；不能把目录中存在切片误报为“已入库”。
- 现有项目的 `EmbeddingProvider`、`RAGPipeline`、MiMo V2.5 题图识别、GeoGebra 服务和课堂数学验证器必须优先复用；不新增第二套向量库、图形 DSL 或 OCR 管线。
- 任何生成结果都不能根据金标准题目标题、关键词或固定答案放行。金标准仅位于测试夹具与验收脚本，生产路径不得读取它们。

## 架构

### 1. 教材入库与知识点索引

恢复本地 BGE-M3 模型和现有 OpenAI 兼容 embeddings 服务。导入前对五册白名单教材做完整性检查；成功获取全部 1024 维向量后，在一个事务内写入教材文档和切片。

知识点树由教材已有的册别、章/节、小节标题建立，并与现有 `knowledge_points` 表的高中数学 code/alias 规则兼容。每个教材切片至少保留：`book_id`、`book_name`、`volume`、`section`、`subsection`、`source_chunk_id`、教材知识点 ID。导入失败时整批回滚，不留下半本教材或空向量。

### 2. 课堂 Agentic RAG 编排

新编排层不替换 `RAGPipeline`：

1. 手输知识点直接形成检索计划；题图先由 MiMo V2.5 输出题干、已知条件、图形实体与不确定项。
2. 题图存在不确定条件或低置信度时，停止课堂生成并要求学生确认，不能把不确定内容当作题设。
3. 基于主题、条件和教材知识点执行既有 scoped hybrid retrieval 与已有 rerank；学生课堂只检索 `scope=student`、`corpus_class=student_textbook`。
4. 只将有来源的教材切片作为讲解上下文；生成产物携带引用的册、章/节、切片 ID 和检索理由。
5. 既有数学验证器验证每页公式、推导和已声明几何关系。验证失败、证据不足或题设未确认时，课堂状态必须是待复核/待确认，而不是 ready。

### 3. 图形与教材关联

已有 GeoGebra 分支只在以下条件同时满足时运行：题图/题干给出可靠且完整的作图条件、关联教学页数学验证通过、存在教材引用。图形生成应使用已识别的条件和已验证讲解，不能默认补点、补长度或默认立体。

不满足图形条件时，后端输出结构化 `textbook_association` block，前端在“图形示意”栏展示教材关联卡：教材名称、册别、章/节、相关片段、与本页的关联理由及可追溯 chunk ID。没有教材证据时，该栏明确显示“暂无可引用教材证据”，不能显示伪引用。

### 4. 验收与质量闸门

验收使用两道独立的真实高中数学综合题：

- 函数综合题：含导数、临界点、单调区间与极值/参数条件的多步推导。
- 空间几何综合题：含题图、条件确认、证明或距离/角度计算，要求图形与推导一致。

每题必须经历真实输入或拍题、检索、课堂生成、通用数学验证、图形或教材关联、浏览器截图。验收输出包括输入、命中的教材引用、每页验证结果、最终答案核验和截图。不能以 API 返回 200、静态 mock、预置模板或无证据的“课堂已完成”作为通过标准。

## 故障处理

- 向量服务不可用：拒绝教材写库；课堂保留为待复核，不伪造教材证据。
- BGE-M3 权重不完整：服务健康检查失败；不允许用随机/零向量代替。
- MiMo 识别失败：沿用既有 OCR/视觉兜底，但仍须携带置信度与不确定项。
- 检索无命中：展示无证据状态，允许教师/学生修改输入，不自动拼接通用话术。
- GeoGebra 失败：保留教材关联和讲解验证结果，记录视觉验收未通过；不能用默认 3D 实体补位。

## 测试策略

- 单元测试：教材白名单、章节/知识点映射、原子入库、检索计划、证据块、图形决策和空图替换。
- 集成测试：本地向量服务的真实 `/health` 与 `/v1/embeddings`，五册导入后的检索命中和引用元数据。
- 端到端测试：两个金标准题实际调用后端并在 5176 页面截图；检验答案、推导、教材引用和图形/教材关联。

## 非目标

- 不新建自研数学验证器、图形 DSL、OCR 管线或第二向量数据库。
- 不导入教师用书、题库或研究材料作为学生教材引用。
- 不为两道验收题添加生产特判、固定答案或关键词路由。
