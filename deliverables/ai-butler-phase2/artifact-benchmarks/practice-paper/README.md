## 对 AI 生成物的验收标准（练习卷）

1. **结构完整性**：整卷须含明确的题型分区（单选/多选/填空/解答）、题号连续、每题标注分值；解答题须按小问拆分设问并分步给分，总分 150 分闭合。
2. **数学正确性**：所有公式、符号（集合、复数、导数、概率记号）须排版正确；每道题必须有唯一确定的答案，选择题选项不得互相包含或全错。
3. **难度梯度**：题目须呈"基础→中档→压轴"的梯度分布，压轴题（如导数、解析几何大题）应设置 2-3 个递进小问，而不是平铺直叙。
4. **内容原创与无泄漏**：题目不得与真题库原文重复（可参考 GAOKAO-Bench 数据查重）；情境题的数据须自洽（数字经过计算验证，不能出现无解或多解）。
5. **排版可用性**：输出为 PDF/可打印版式时，题干不得跨页断裂、图文（函数图/几何图）位置正确；文字层可复制可检索，图片版须 >=200 DPI。
6. **表达规范**：题干表述简洁、条件无歧义、不出现"根据所学知识"等空话；填空题答案空间预留、选择题选项长度均衡。
