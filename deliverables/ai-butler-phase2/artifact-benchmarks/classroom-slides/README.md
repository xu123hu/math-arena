## 对 AI 生成物的验收标准（课堂讲义/课件）

1. **课堂结构完整**：课件须有明确的教学环节（复习引入→概念/定理讲解→例题精讲→课堂练习→小结作业），页数与 40-45 分钟课堂容量匹配（约 15-30 页），不得一页塞入超过一个主知识点。
2. **知识准确性**：定义、定理表述须严谨（条件不缺失），公式推导无跳步错误；例题须先给题目再逐步解答，解答步骤可评分点化。
3. **版式与可读性**：标题层级清晰（章-节-页），字号投影可读（正文 >=20pt），"定义/例题/易错"等区块用颜色或边框明确区分（对标 ColorMath 模板）；图示须与同页文字对应，不得图文分离。
4. **内容密度对标**：概念课须"每页一个概念+图示+一个即时例"，方法课须"一页一个方法卡片+例题+变式"（对标 libpku 系列）；复习讲义须"一页一考点+典型例题+易错警示"。
5. **教学导向表达**：须体现启发式设计（设问、追问、留白让学生先算），不得是知识点罗列的"文档搬运"；例题选择须有代表性并标注来源或改编说明。
6. **文件规格**：PPTX 须为可编辑原生格式（文本框非整页图片），打开无字体缺失导致的乱码；数学公式须用公式对象或清晰排版，不得出现 ASCII 乱码（如 `f(x)={x^2,x>0`）。
