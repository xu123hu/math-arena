## 对 AI 生成物的验收标准（T-B2/T-B3 产出 vs 本基准并排对比）

1. **结构对齐官方规范**：讲评报告 ≥三段——总体结论 → 逐题/知识点归因 → 教学建议（对照烟台/黄冈文件要素），禁止只有数据没有建议。
2. **交叉表必备**：班级（或学生分层）× 题号/知识点的得分率交叉表，按得分率升序突出最差项（对照五指山中学表）。
3. **口径诚实**：统计口径标注清晰（满分 150、样本数、平均分/标准差/难度系数），禁止无样本量的百分比（对照 150 分制表与华南师大指标）。
4. **数据可追溯**：报告每个结论可点回原始作业/考试数据（数据不编造——与「数据失真零容忍」画像红线一致）。
5. **教学建议可执行**：建议具体到「哪道题/哪个知识点/下一步动作（重讲/变式/个别辅导）」，禁止「加强练习」式空话。
6. **中文表达**：教研口吻、术语规范（得分率/区分度/标准差），禁止 AI 腔与虚构学校名。
