## 三、链路卡全集

### S-B1 · 悬浮球唤起与管家对话（学生端入口枢纽）

- **对应画像与场景**：S1 全场景——任何页面任何时刻想"使唤"平台（出题/上课/解题/问学情）。
- **入口**：①全站右下角悬浮球（`V4Layout` 顶层新增节点，所有学生页可见；`/dual` 沉浸页折叠为小角标，不打断学课）；②快捷键 `Ctrl/⌘+K`（对齐教师端既有习惯）；③业务页内"问管家"上下文入口（练题/错题/课堂页，预填当前页语境，如"这道错题给我讲讲"）。
- **步骤**：1 点击悬浮球 → 球体展开为对话面板（**悬浮窗 ↔ 侧边栏双形态可切换**，Notion 模式；记住用户上次形态）→ 2 输入文字 / 上传图片 / 点快捷芯片（出题·上课·解题）→ 3 管家 v2 runtime 意图识别（Planner）：执行类意图分别转 **S-B2 / S-B3 / S-B4**；咨询类（学情/规划）流式回答 → 4 面板内回执卡（任务号+进度入口）。
- **数据**：会话与消息复用 `conversations`/`messages`；管家场景 `student.chat` 登记 v2（shadow 期只记账不执行）；`agent_runs` 全记账。
- **异常与降级**：①LLM 不可用 → 关键词规则兜底路由到三工具 + 提示"智能理解暂不可用"；②面板打开失败 → toast 可重试，禁白屏；③ Planner 失败 → v2 确定性 fallback plan（既有机制）。
- **闭环**：得到答复或任务回执卡；下一步引导 = 回执卡按钮（查看练习 / 进入课堂 / 查看解题 / 任务中心）。
- **连接**：S-B2/S-B3/S-B4 总入口；S-B5/S-B6 状态徽标常驻球体。

### S-B2 · 对话下单出题 → 后台生成 → 通知 → 进入练习（★黄金路径）

- **对应画像与场景**：S1 晚自习："生成关于圆锥曲线的 30 分钟模式的练题"——提交后想先背单词，练题好了再回来。
- **入口**：①S-B1 对话（自然语言）；②练题中心选"30 分钟模式"后若需 AI 补题 → 自动转后台任务，页面顶部出现"正在补充题目，可先做已有题"胶囊（既有同步出题改造为双模：题库够→秒开同步；需 AI 补→后台任务）。
- **步骤**：1 用户发起 → 2 参数缺失时管家澄清卡（知识点/模式/时长，点选补齐，不强制打字）→ 3 创建任务 `tasks(kind=practice.generate, payload={kp_ids, mode, duration, question_count})`，立即回执卡"已开始生成，可离开页面" → 4 后台 TaskRunner 调用**练题中心同一出题内核**（题库优先 → AI 补缺口 → 五闸质检；单一内核纪律，管家不另写生成逻辑）→ 5 球体/任务中心显示进度（题面 n/m）→ 6 终态通知（红点 + 气泡："圆锥曲线 30 分钟练习已生成"）→ 7 点通知/任务卡 → 进入 PracticeView 沉浸答题（练习集已自动保存至练习记录）→ 8 做题判分 → 错题 100% 自动收录错题本（衔接既有判分链）。
- **数据**：`tasks` 行（result=练习集 id）；练习集落既有练题表；判分错题落 `error_records`；通知落 `notifications`；`agent_runs/agent_steps/tool_invocations` 可追溯。
- **异常与降级**：①AI 补题部分失败 → 题库兜底组卷并在任务卡注明"以题库题为主"；②五闸高失败 → 任务 failed + 原因 + **一键重试**（幂等键防重复产物）；③学生日刷题上限已达 → 友好拒绝 + "明日再来"提醒选项；④主模型熔断 → ModelRouter 自动降级 MiMo（既有）；⑤运行中可取消（queued/running）。
- **闭环**：完整练题体验 + 错题入库；引导 = 错题本复习 / "让管家讲讲这道错题"（转 S-B4）。
- **连接**：S-B1 入口；S-B5 状态；S-B6 通知；既有练题链路与错题链路收尾。

### S-B3 · 对话下单双师课堂 → 后台生成 → 历史课堂

- **对应画像与场景**：S1 想系统学一个专题："生成一个关于圆锥曲线的课堂"。
- **入口**：①S-B1 对话；②双师课堂页既有创建入口（任务化增强通知与历史）。
- **步骤**：1 发起 → 2 澄清卡（主题/难度/页数偏好）→ 3 建任务 `kind=classroom.session`（内部复用既有 `POST /classroom/sessions` 逻辑；课程未就绪则先链式 `course.preprocess` 子任务并告知预计时间）→ 4 后台生成（大纲 → 逐页 → 分层练习，进度事件沿用既有 events 流）→ 5 通知"课堂已生成，共 n 页" → 6 跳 `/dual/{id}`（SSE 直播 + 轮询兜底 UI 既有）→ 7 学课完成 → 课堂自动保存在历史课堂列表可回看。
- **数据**：`classroom_sessions`（既有表，产物在此）+ `tasks` 行（result=session_id）；`notifications`。
- **异常与降级**：①课程未就绪 → 自动预处理子任务，进度可见；②单页生成失败 → session failed + **失败课堂在历史中可见不再静默排除**（修复 student-ai-upgrade §7.2 缺口1）+ 重试（含单页重生成既有能力）；③离开页面生成不中断（既有 create_task 范式保证）。
- **闭环**：学完课堂 → 引导做配套分层练习（om6 practice 数据）→ 错题链。
- **连接**：S-B1 入口；S-B5/S-B6；既有课堂链路全程复用。

### S-B4 · 拍照/文字转引导式解题 → 后台解题 → 通知查看

- **对应画像与场景**：S1 作业/试卷遇到不会的题，不想干等（现状：引导解题开场 22.3s 且必须守着页面）。
- **入口**：①S-B1 对话上传图片或文字描述；②错题本"问管家"（**补学生端场景清单 D2 缺口：错题→引导重解无入口**，管家即新入口，携带原错题上下文）；③对话页 skill 直选 `/解题`（既有同步形态保留，两条路同一技能）。
- **步骤**：1 上传图片/描述 → 2 管家识别解题意图 → 建任务 `kind=socratic.autosolve`（payload：file_id/题面/来源错题 id）→ 3 后台：视觉通道解析题面 → `socratic_solver` 技能后台跑完整引导链（**不泄题纪律保持**：引导式推进，最终含正解与变式，正解折叠）→ 4 会话落库（`messages`，skill=socratic_solver，附件元数据保留）→ 5 通知"解题完毕" → 6 点开进入对话页查看引导过程，**可继续追问**（交互接管，幂等重放机制保证现场还原）→ 7 若答错/来自错题 → 自动联动错题本。
- **数据**：`tasks`；`conversations/messages`（含 attachments）；`error_records`；`ai_calls` 审计。
- **异常与降级**：①图片模糊/OCR 低置信 → 任务失败并说明"请重拍更清晰"，一键重传；②solver 中途失败 → 会话落 interrupted 标记（既有 `_spawn_partial_persist` 语义）+ 任务可重跑；③后台解题期间用户等不及 → 可直接打开会话看已生成的部分。
- **闭环**：解题会话沉淀在对话历史；引导 = 变式练习（短链转 S-B2 单题变式）。
- **连接**：S-B1/S-B5；错题链（D1/D2 衔接面修复）；对话学习链。

### S-B5 · 任务中心（双端同组件，学生视图）

- **对应画像与场景**：S1"我提交的活儿到哪一步了？"；T1"批改/材料生成好了吗？"
- **入口**：①悬浮球徽标/列表图标；②S-B6 通知点击落地；③业务页顶部"后台任务"胶囊（生成中常驻显示）。
- **步骤**：1 打开任务列表（进行中带进度条 / 已完成 / 失败，按时间倒序）→ 2 点进行中 → 展开详情（阶段文案、已等待时长、取消按钮）→ 3 点已完成 → 跳产物落点（练习/课堂/会话/工件）→ 4 点失败 → 原因 + 重试（幂等）→ 5 可清空已完成。
- **数据**：`tasks` 表（按 user_id + 角色）；增量轮询 `GET /api/tasks?since=`（形状对齐 Open WebUI 事件语义，为二期 WebSocket 留口）。
- **异常与降级**：①列表拉取失败 → 骨架屏 + 重试按钮（禁永久转圈纪律）；②进程重启导致任务行悬挂 → stale 自愈扫描恢复状态（classroom 范式推广）；③产物被业务侧删除 → 任务卡降级提示"产物已删除"。
- **闭环**：任何任务都有归宿——产物跳转 / 重试 / 取消。
- **连接**：S-B2/B3/B4、T-B2/B3 的状态面板；教师端 T-B1 复用同组件。

### S-B6 · 完成通知与红点（双端同规则）

- **对应画像与场景**：S1 提交后离开，回来前想知道"好了没"；T1 手机看通知的习惯。
- **入口**：球体角标 / 顶栏铃铛位（学生端 V4Layout 顶栏新增铃铛，教师端沿用既有铃铛扩展数据源）。
- **步骤**：1 任务终态 → 产生通知（一句话摘要 + 产物类型图标）→ 2 球体角标 +1 → 3 展开通知列表（未读/已读）→ 4 点击单条 → 跳产物；5 **降噪纪律**（继承 butler v3.0 方案）：任务进行中不推、同任务不重复推、做题沉浸模式静默（ai_mode=locked）、每日主动条数沿用 butler_proactive_limit、学生可按 scene 关闭。
- **数据**：`notifications` 表（新建：user_id/type/payload/read_at/created_at）；已读状态。
- **异常与降级**：通知服务异常 → 降级为仅任务中心可见（不阻塞主链路）；离线期间完成的任务 → 回来时角标汇总展示。
- **连接**：所有任务链的统一出口；点击落点即各产物链入口。

### T-B1 · 教师端管家唤起升级（ButlerPanel → 悬浮球双形态）

- **对应画像与场景**：T1 批改间隙唤起；T2 备课时下单一套卷。
- **入口**：①`⌘K`（既有）；②顶栏"教学助手"（既有）；③右下角悬浮球（新增，与面板同态切换）。
- **步骤**：唤起 → 对话 / 快捷芯片（组卷·材料·批改进度）→ 执行类意图转 T-B2/T-B3 → 回执卡 + 球体进度 → 通知红点复用 S-B6 组件。
- **数据**：沿用 `/api/teacher/butler/chat` 通道 + 新 `tasks` 表（teacher_tasks 渐进迁移，本期只读并行不双写）。
- **异常与降级**：OPTIONS 探测 404 → 面板禁用（既有）且悬浮球隐藏；幂等键每消息独立（既有 useButlerScene 纪律）。
- **闭环**：答复或任务回执卡 → 跳工件/任务中心。
- **连接**：T-B2/T-B3；S-B5/S-B6 组件复用；教师 L 链路网。

### T-B2 · 对话下单组卷 → 后台生成 → 预览 → 一键布置

- **对应画像与场景**：T2 李老师晚备课："按这周课题出一份 45 分钟练习"。
- **入口**：①T-B1 对话；②备课页 AI 组卷入口（任务化改造）。
- **步骤**：1 发起 → 2 澄清卡（班级/课题/难度/题量/时长）→ 3 任务 `kind=teacher.quiz.create`（既有教师工具转后台执行）→ 4 后台走教师出题内核（五闸 + 教参对齐，不绕过质检）→ 5 通知 → 6 点开 ArtifactPanel 预览试卷（逐题来源/考点可见）→ 7 "一键布置"进既有布置作业链路（L2/L3）。
- **数据**：`tasks` + `teaching_artifacts`（既有）+ 试卷数据。
- **异常与降级**：部分题未过质量闸 → **部分成功报告**（"n 道达标、m 道待重生成"，逐题重试，不许整卷静默降质）；其余同 S-B2。
- **闭环**：布置 → 批改（L4）→ 讲评（L5）既有教师主链。
- **连接**：T-B1；S-B5/S-B6；教师 L 链。

### T-B3 · 对话下单教学材料（讲评材料 / 课件 / 教案）→ 后台生成

- **对应画像与场景**：T1 批改完想 30 分钟内拿到讲评材料；T2 "把导数教案做成课件"。
- **入口**：T-B1 对话。
- **步骤**：1 发起 → 2 澄清（类型 + 来源：某次作业/某课题 artifact）→ 3 任务 `kind=teacher.materials` → 4 后台聚合数据 + LLM 生成（讲评=错题聚类 + 讲评建议，复用既有班级洞察内核；课件=slides.create 既有工具）→ 5 通知 → 6 ArtifactPanel 预览 / 下载 → 7 可挂到课堂会话。
- **数据**：`tasks` + `teaching_artifacts` + `agent_runs` 记账。
- **异常与降级**：①数据前置校验失败（如该作业未批改完成）→ 明确告知缺什么、先去做什么；②生成失败 → 原因 + 重试。**全程修复 P-04「生成 PPT 无响应」**：所有生成动作必有进度/失败/重试三态。
- **闭环**：材料进讲评（L5）/课堂（L6）链路。
- **连接**：T-B1；教师 L 链；S-B5/S-B6。

## 四、黄金路径声明

**S-B2（扩展闭环版）：学生说"生成圆锥曲线 30 分钟练题" → 后台生成（可离开页面）→ 完成通知 → 进入练习 → 判分 → 错题自动收录 → 管家引导错题重解。**

选择理由：①唯一一条同时演示四大新能力（管家编排、后台任务、通知、自动保存）的链路；②落点直通平台核心学习闭环（练题→错题→重解），符合 S1"第一分钟"画像；③直击用户命题原话第一例。**资源倾斜**：阶段 3 按"黄金路径先端到端打通并留证，再补其余链路"执行；阶段 2 优先为 S-B2 写双轨验收用例。
