## 一、体验结论（一句话）

**产品的「骨架」搭得很大（12 个页面 + 学习闭环 7 步 + FSRS 记忆曲线），但「血液」断了——核心 AI 链路全线 500，错题本被两条一模一样的 demo「解三角形」污染，前后端接口对不上，导致学生打开后只会反复看到同一道解三角形题、永远转圈的「AI 生成中」、永远加载失败的面板。这不是"功能少"，是"半成品里埋了一堆断线"。**

## 三、根因定位（已读源码 + 实测 API 确认）

> 实测后端 `GET /api/health/models` 返回：`spark: ok=false, 401 Unauthorized (spark-api-open.xf-yun.com)`；`deepseek: ok=true, model=mimo-v2.5-pro, 延迟3.5s`；`embedding: ok=false, [Errno 22] Invalid argument`。

1. **星火主通道 401 认证失败（已实测确认）** — `.env` 的 `SPARK_API_PASSWORD` 发给 `spark-api-open.xf-yun.com/v1/chat/completions` 返回 **401 Unauthorized**，key 错误/失效。
2. **备通道 "DeepSeek" 其实是小米 MiMo（已实测确认可用）** — `DEEPSEEK_BASE_URL = https://api.xiaomimimo.com/v1/chat/completions`、`DEEPSEEK_MODEL = mimo-v2.5-pro`，健康检查 `ok:true`。chat 理论上能靠它兜底，但主通道 401 让每次 AI 调用都先白等一次星火失败再降级（每次 +3.5s 延迟）。
3. **embedding 通道坏（已实测确认）** — `config.py:36` `embedding_base_url = http://localhost:8080`（本地 embedding 服务未启动）→ `[Errno 22] Invalid argument`。
4. **`_cached_report` 装饰器 await bug（代码级确认，导致 report/* 全部 500）** — `growth_router.py:73`：
   `data = await factory() if iscoroutinefunction(factory) else factory()`
   `factory` 永远是 `lambda: func(...)`，`inspect.iscoroutinefunction(lambda)` 恒为 False，于是走 `factory()` **只返回未 await 的协程**，`_ok()` 把协程塞进 JSON → 响应序列化炸掉 → 500。**这解释了 highlights/weak-points/error-distribution/honesty 四个 `@_cache_report` 端点全部 500。**
5. **`growth_llm_polish=True` 默认开启（`config.py:96`）+ 主通道 401** — overview/panel/today-3 每次都要走 LLM 润色链路；这些端点 500 返回的是**纯文本 `Internal Server Error`**（而非 `main.py:126` 全局异常处理器的 JSON 信封），说明异常逃逸了 `Exception` 处理器。修复：给 growth 端点加 try/except 兜底 + 修星火 key + 修 `_cached_report`。
6. **前端 `butlerApi` 缺方法** — `D:\frontend\src\api\index.js:99-110` 缺 `errorDetail`、`errorTutor`（后端 `butler_router.py:179/193` 已有）。
7. **「去练题」不带知识点** — `D:\frontend\src\pages\student\ErrorsView.vue:505-507` `goPractice()` 未带 kp。
8. **5 题 vs 1 题** — 后端 `student_router.py:846` daily 模式固定 `count=1`；前端 `PracticeView.vue:390` 新用户走 daily，但 UI 写死 5 题。
9. **解三角形 demo 数据污染** — `services/api/scripts/seed_demo_bank.py:177` 种子题 + 该账号重复收录 2 次。

> 实测端点矩阵（新账号）：**500** = growth/overview、growth/panel、growth/today-3、report/highlights、report/weak-points、report/error-distribution、report/honesty；**200** = growth/score-trend、report/mastery-trend-forecast、knowledge-graph/pie、knowledge-graph/tree、error-records/memory-heatmap、growth/loop-progress。**规律：走了 LLM 润色/装饰器缓存逻辑的端点就 500，纯 DB 聚合的端点正常。**
