## 0. 前置纪律（每条链路卡必须显式遵循）

1. **出题只走一条带闸实现**（实施纪律 1）：教师端 L2/L3 的所有 AI 出题走 `skills/smart_quiz/run_quiz_gates` + `verify_answer_key`（资产 #2），禁止另造质量闸；当前违规点 = `capability_gateway._local_quiz` 纯题库检索不过五闸（债清单）。
2. **不绕过 confirm 幂等与 scope 校验**（资产 #12 条款）：所有 L4 新功能、批后讲评/聚类等下游链必须走 `grading.py:265-317` advisory lock + binding 指纹台账；所有教师域越权断言走 `tests/test_m3_teacher_scope.py` 16 例模式（覆盖 token/绑定/软删/跨教师）。
3. **优雅降级明示状态**（红线 8/纪律）：星辰/星火/DeepSeek 不可用时显式 `degraded: true` + 原因字段，**禁止静默**；降级文案走统一文案模板（不暴露 `count=` 等原始字段——§3.1 已修，阶段 2 固化）。
4. **L4 先于 L5 硬约束**：讲评建议（`grading_review_insights`）只看 `verdict==wrong`；主观题无 verdict 时 L5 对主观题沉默——L4 P0-2 修复是 L5 数据真实性的前置。
5. **契约登记先于改动**（红线 8）：任何 L1~L8 端点的字段/枚举/语义变更先写 `deliverables/教师端契约变更记录.md`。

## L1 今日工作台 `/teacher/today`

- **入口**：`GET /api/teacher/today`（教师登录后即达）。
- **步骤**：聚合四块→①待批作答数 ②下一节课卡（课题/班/完成度/缺口/时长/教室，本批 C 提交新增 6 字段）③需要处理列表（洞察→行动跳转）④快捷工作入口。
- **数据**：`today.py:_next_lesson`（含备课完成度聚合）、insights 持久化 fast path（`insights.py:298-314`）、grading 队列统计。
- **异常降级**：
  - LLM 不可用→本日洞察仅展示确定性聚合（待批数、提交量、复习积压），不调用讲评生成；
  - 无教案时 `prep_completion=null`，前端显示「开始备课」入口而非「继续备课」（已修，需在 §2 验收中固化）；
  - 每班聚合首次慢（today 循环 `today.py:209-216`）→ 持久化 fast path 已缓解，**P1-6 优化作为非阻塞债**。
- **闭环**：洞察→L4 批改/讲评链、L3 组卷提示、L2 备课入口。
- **断头路清零**：诊断 T-01「同学老师」称呼 bug、T-02 原始字段（`count=5`）→ §3.1 阶段 2 用例固化文案（已修，不出现在前端 mock）；T-04 洞察质量低（只计数）→ 本批 C 新增 `error_cluster` 已扩展洞察源。

## L2 备课（教案/课件）`/teacher/prep`

- **入口**：`GET /teacher/lessons`（列表）→ 新建课题（前端契约新增课题输入）→ `POST /lessons/adapt` → 产物 confirm → `POST /lessons/{id}/slides` → 下载。
- **步骤**：
  1. 教师输入课题（前端契约 P-01 修复点）；
  2. `POST /lessons/adapt` 调 `lessons.adapt_lesson` → 星辰/MiMo/DeepSeek 三通道；
  3. 产物 confirm → 写 artifact；
  4. `POST /lessons/{id}/slides` 调 LLM 真实生成 PPT（接 ModelRouter）；
  5. GET 下载。
- **数据**：`lessons.py`（含 `lesson_basic_template` 兜底）、artifact 生命周期、教师 19 工具中的备课写入（受 WRITE 通道+幂等约束）。
- **异常降级**：
  - 星辰不可用（**当前实情：欠费 20373**）→ ModelRouter 降级到 DeepSeek → 若 DeepSeek 也不可用 → `degraded: true` + 基础结构骨架（**禁止恒模板兜底**：现状断点 j 已确认，阶段 3 必修）；
  - 切通道由 ModelRouter 单通道纪律接管（资产 #7 保留），降级明示在响应 envelope；
  - 课程切片超时（30s）→ 返回可重试，不静默；
  - 采纳建议端点（前端契约记录 FE→BE 第 3 条已 accepted）= `POST /lessons/{lesson_id}/adopt-suggestion`（**阶段 2/3 实现**，阶段 1 仅定契约）。
- **闭环**：`prepared_artifact` → L3 课堂开场可直接 attach、L5 学情可引用教案。
- **断头路清零**：P-01 课题输入（前端契约 + 后端入参 `topic` 必填）、P-02 「不知道」兜底（移除硬编码 LLM 失败文案）、P-04 生成 PPT 无响应（接 `POST /slides` 真实调用+下载触发）。**P-03 时间线空壳**随 LLM 路径修复自动消解。
- **前端契约对接**（来自契约记录）：`POST /teacher/lessons/{id}/adopt-suggestion` 入参 `lesson_id+segment_id+suggestion_id+可选 content`，出参 = 更新后 artifact。

## L3 组卷布置 `/teacher/assign`

- **入口**：`POST /teacher/quizzes/generate`（含 `class_id / kp_codes / 难度比例 / 题量 / 预计用时`）→ 试卷预览 → `POST /teacher/assignments` → `POST /assignments/{id}/publish`。
- **步骤**：
  1. 知识点选择（前端已实现细目表下拉，前端版 §2.3 L3 描述为“工程标杆”）；
  2. 后端 `capability_gateway._local_quiz` 出题 → 阶段 3 改造：接 `skills/question_supply`（两阶段检索：题库优先 + AI 补题）→ **必经 smart_quiz 五闸**（纪律 1）；
  3. 试卷逐题附 `source_label`（`source=真题 / AI生成·已过五闸`）——通宵报告阶段 3 学生侧已通，**教师侧必须在同一通道上复用**；
  4. 教师 confirm → artifact 入库；
  5. 发布到班级（`ClassMember` 范围）。
- **数据**：`quizzes / quiz_items / assignments / assignment_items / source_artifact_id`、题库（资产 #1，901/4,767 口径）。
- **异常降级**：
  - 题库不足 → N-1 成组（学生侧 J3/F6 规则：`min(ceil(0.7n), n-1)`） + 不足部分用「AI 生成·已过五闸」标签补足（通宵报告 §二 J3 验证已通过）；
  - 五闸任一失败 → 题卡回退一次后仍失败**明确拒出**（`suggested, conf = 0` + `degraded: true`），禁止用模板重复题凑数（A-02 文不对题根因）；
  - 不可达出题请求 → 422 + 题源为空提示（前端引导扩范围，A-05）。
- **闭环**：artifact → L4 作业发布后学生作答 → L4→L5 讲评反馈。
- **风险点 2（资产评估 §四）落地**：本链路验收用例必须断言**「教师组卷返回的每题都经五闸」**（不许过 `capability_gateway._local_quiz` 纯检索通道）——这是单一内核纪律的硬约束。

- **异常降级**：

  - `verdict` 缺失 → confirm 必走人工；

- **闭环**：verdict → L5 `error_cluster` 聚类 + `grading_review_insights` 讲评。
- **断头路清零**：G-01 题干/题型（已在 HEAD 修复，**本批新增 image 字段**）；G-02 学生姓名=匿名设计，非缺陷，阶段 2 用例文档化；G-04 待处理数不一致（grading/today 双数据源）→ 阶段 2 体验轨用例断言。
- **风险点 1 落地**：验收用例必须**对 `grading.py:456-461` 与 `capability_gateway.py:226-227` 两处双源都打靶**——任何一处仍输出 0.0 草稿即视为用例失败。
