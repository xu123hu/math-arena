## 三、关键题目级验证证据

### 3.1 四棱锥（2023 甲卷理 11）——本次事故同类题
- 题目条件：底面正方形 AB=4，PC=PD=3，∠PCA=45°。
- 参数化渲染：解析求解 P=(0,1,2)，校验 `PC=PD=3.000000`、`cos∠PCA=0.707107=cos45°`。
- 渲染不变量：`P.y=55 < min(A,B,C,D).y=191`——**顶点严格位于底面上方**（SVG y 向下，值小者在上）。
- 旧 AI 配图对比：见 §五。

### 3.2 三棱锥（2023 甲卷文 10）
- PA=PB=2、PC=√6、底面正三角形边长 2——六条边长逐条对拍，误差 <1e-9。
- 虚线边：仅 P-C（被遮挡的棱），与教材画法一致。

### 3.3 球内接几何体（外接球/内切球四题）
- 2010 理7：长方体 2a×a×a 外接球 r=√6/2≈1.2247 ✓
- 2016 理4：正方体 a=2 外接球 r=√3≈1.7321 ✓
- 2010 理10：正三棱柱外接球 r=√(h²/4+a²/3) ✓
- 2016 理11：直三棱柱内切球 r=1.5（min(底面内切圆 2, 高/2)）✓
- 所有内接几何体顶点均落在球面上（2022 题逐点校验 |v|=1）。

### 3.4 函数图像
- y=x²−2x−3：顶点 (1,−4)、零点 (−1,0)/(3,0) 以圆点+坐标标注，位置由参数直接投影（无采样误差）。
- y=tanx：在 x=±π/2 渐近线处断开为 3 条 path，无假竖线（防"渐近线画成实线"的常见错误）。
- 采样：递归中点细分（段内线性误差 ≤1e-3），sinx 全程连续单路径。

## 五、AI 自由生成 vs 参数化渲染对比

| 维度 | 旧：MiMo 自由生成 SVG | 新：参数化渲染 |
|---|---|---|
| 几何正确性 | 随机：实测出现"四棱锥顶点 P 画在底面内部" | 代码投影 + 不变量断言，**不可能**出现顶点在底面内（渲染即报错） |
| 数值一致性 | 无（画图不保证边长/角度） | 边长/角度/半径由题目条件解析求解，逐项对拍 1e-9 |
| 隐藏线 | 时对时错 | 凸多面体 backface culling，教材画法（如四棱锥仅 P-D 虚线） |
| 确定性 | 每次调用结果不同 | 同参数永远同 SVG（测试断言） |
| 可校验性 | 只能人眼查 | 参数 JSON + 不变量断言全自动 |
| 成本 | 每题一次 LLM 调用 | 规则题零 LLM；LLM 兜底仅提取参数（渲染免费） |
| 失败模式 | 静默画错 | 校验失败保留原图并记录，绝不覆盖成坏图 |

对比样例（MiMo 对照生成结果见 `deliverables/figure-renderer/samples/` 与 §六）。

### 5.1 实测证据（同题同管线对拍）

用**同一道 2023 甲卷理 11 四棱锥题**分别跑旧/新管线，程序化检测结果：

**旧管线（MiMo 自由生成，`backfill_figures.gen_svg`）**：
```
顶点 P 位于底面内部/下方（P.y=245 ≥ 底面最高点 y=45）  ← 原事故完整复现
文本标注 5 处；虚线样式 0 处；无填充面
```

**新管线（LLM 提取参数 + 代码渲染）**：
```
type=quad_pyramid  P.y=55 < min(A,B,C,D).y=191（顶点严格在底面上方）
隐藏边 P-D 虚线；底面/可见棱面半透明填充；PC=PD=3、∠PCA=45° 逐项对拍 1e-9
```

另以合成题验证 LLM 提取路径（DeepSeek 仅输出 JSON 参数）：
- "四棱锥底面边长 2、PA⊥底面、PA=3" → `{"type":"quad_pyramid","params":{"base_w":2,"base_d":2,"height":3,...}}` ✅ 渲染无 fatal
- "f(x)=x³−3x 标出极值点" → `{"type":"function","params":{"curves":[{"expr":"x**3-3*x",...}],"points":[{x:-1,y:2,label:"极大值"},...]}}` ✅ 渲染无 fatal
