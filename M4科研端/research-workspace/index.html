  16.   ∃ C > 0, ∀ k : ℕ, ‖A ^ k‖ ≤ C * (1 + ε) ^ k := by
  17.   have h1 := spectralRadius_le_one_iff.mp h_spec
  18.   have h2 : ∀ k, ‖A ^ k‖ ≤ ‖A‖ ^ k := by

  20.     | zero => simp
  21.     | succ k ih =>
  22.       calc ‖A ^ (k + 1)‖ = ‖A ^ k * A‖ := by rw [pow_succ]
  23.         _ ≤ ‖A ^ k‖ * ‖A‖ := norm_mul_le _ _
  24.         _ ≤ ‖A‖ ^ k * ‖A‖ := mul_le_mul_of_nonneg_right ih (norm_nonneg _)

3.2 收敛性分析

本节我们对所提出的 GNN 路径规划模型进行严格的收敛性分析。我们将证明，在满足一定图结构条件下，模型的迭代过程以指数速率收敛到稳态解。

定义 3.1（GNN 迭代算子）设 A 为图的邻接矩阵，定义 GNN 迭代算子 T(x) = σ(Ax + b)。

定理 3.2（主收敛定理）设图 G 为无向连通图，邻接矩阵为 A。若谱半径 ρ(A) ≤ 1，则存在常数 C > 0 和 ε ≥ 0，使得对任意正整数 k，有：

‖Ak‖ ≤ C · (1 + ε)k

其中 ε 与图的平均度相关。
