# M4 科研端开发前准备与高保真原型实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付统一的 README、API 契约、需求基线和可本地运行的高保真科研端 HTML 原型，并完成自动化与人工浏览器验收。

**Architecture:** 原型采用无构建依赖的模块化 HTML/CSS/JavaScript，可直接打开或由静态服务器运行。产品与接口统一使用 Project、Run、Evidence、Capability 四个核心模型；运行路径明确区分 FULL、LOCAL_ENGINE、BROWSER_LOCAL 和 UNAVAILABLE。

**Tech Stack:** HTML5、CSS3、原生 ES Modules、LocalStorage/IndexedDB 演示适配、ARIA；文档为 Markdown；验收使用浏览器自动化、DOM 断言和截图走查。

**Spec:** `D:/M2开发/M4科研端/M4_科研端详细需求分析.md`

## Global Constraints

- Lean4 只在后端正式运行和构建；浏览器离线模式不得显示“证明成功”。
- AI 只生成建议或待确认草案；确定性结论来自 SymPy、Lean kernel、规则或数据引擎。
- 验证四态固定为 pass、unverifiable、counterexample、formal_pending。
- 任何降级结果必须显示 resolved_mode、capabilities_used 和 missing_capabilities。
- 教育聚合数据 k≥20；L2 导出需要双签、水印和审计。
- 原型使用真实中文示例内容，主要页面不得以“建设中”代替。
